# Valo app

The mobile app for [Valo](https://github.com/valo-home/valo), the local smart home hub.

The work has not started yet. Until then the web interface of the hub works on phones: open the address
of your Valo in the phone browser.

Planned
- connection to the hub in the home network and through a TLS proxy from outside
- dashboards, device control, camera video
- push notifications instead of Telegram

Ideas and help are welcome in the issues.
